# 判断推理・数的推理トレーニングルーム（SPI-U / SPI-H 演習アプリ）

SPI-U・SPI-Hの非言語分野のうち、判断推理（順序推理・対応推理・位置推理・発言の真偽・命題論理・対戦成績・物の流れと比率）、数的推理（集合・場合の数・確率・損益算・割合と増加率）、資料解釈を演習できるWebアプリです。

**問題はすべてブラウザ内でその場アルゴリズム生成**されます。外部AI APIやサーバーは不要で、静的ファイルのみでGitHub Pagesにそのまま公開できます。

## 特徴

- **出題区分**：SPI-U（大学生向け）／ SPI-H（高校生向け）を選択
  - 判断推理は、SPI-HでもSPI-Uと同水準の難易度で出題される傾向を踏まえ、要素数・難易度でU/Hの差をつけていません
  - 数的推理・資料解釈は、SPI-Uのほうが数値の規模や計算の段階数（逆算の有無など）が大きくなる傾向を反映し、U/Hで難易度に差をつけています
- **難易度**：中級・上級（いずれも本試験相当のレベル）
- **出題範囲**：以下の13分野・3グループから自由に選択（複数選択可、グループ単位の一括選択も可能）
  - **判断推理**：順序推理／対応推理／位置推理／発言の真偽／命題・論理／対戦成績／物の流れと比率
  - **数的推理**：集合／場合の数／確率／損益算／割合・増加率
  - **資料解釈**：資料解釈
- **出題数**：1〜10問を自由に設定。1回のセット内で問題は重複しません
- **制限時間**：分野・難易度・出題区分に応じて自動設定されるタイマー付き
- **自動採点＋解説**：分野別の正答率、各問題の解答レビューを表示
- **複合選択肢（ア・イ・ウ型）**：順序推理・位置推理・物の流れと比率の一部では、「アとイの両方」のような最大8択の複合選択肢問題も出題されます
- **フロー図の自動描画**：物の流れと比率では、経路と比率をSVG図として自動生成して表示します
- **セットの途中で中断**：クイズ画面の「■ 中断する」ボタンから、途中までの結果をいつでも確認できます
- **分野ごとの公開／非公開切り替え**：精査が済んでいない分野は管理側で非表示にできます（詳しくは下記）

## 問題生成の仕組み（正しさの保証について）

- 順序推理・対応推理・位置推理・発言の真偽：条件（ヒント）をランダム生成した後、**総当たり（全順列／全組み合わせ）で解が一意に定まることを検証**してから出題します。また、単独の条件だけで答えが分かってしまう対象は出題対象から除外しています。
- 命題・論理：前提から機械的に真理値表を作り、選択肢が論理的に導けるか（含意関係にあるか）を**プログラムで判定**しています。
- 対戦成績：総当たりリーグ戦は「全チームの勝ち数の合計＝総試合数」という不変量を持つことを利用し、1チームを除く勝敗数から残り1チームの成績を一意に逆算します。
- 物の流れと比率：比率の掛け算・足し算が割り切れる／100%を超えないことを検証しながら経路を生成します。「式の正誤」を問う問題では、各文字にランダムな数値を代入して実際に計算し、複数パターンで一致するかを確認する方式（数値代入による恒等式検証）で、因数分解などで見た目が異なる式の同値性も正確に判定しています。
- 集合・場合の数・確率・損益算・割合と増加率：先に「正解となる値」を計算で確定させてから問題文を組み立てる方式で、割り切れない・確率が1を超えるといった矛盾が起きないよう生成条件を制限しています。
- 資料解釈：ランダム生成した表データから増加率・構成比を実際に計算して正答を求めています。

そのため出題のたびに内容は変わりますが、常に論理的に一意な正解が存在します。

```
spi-quiz-app/
├── index.html   … 画面構造
├── style.css    … デザイン（受験票・答案用紙・採点スタンプをモチーフにしたUI）

├── LICENSE      … MITライセンス

```

ビルド不要・依存パッケージなしの静的サイトです。

## ローカルで試す

`index.html` をブラウザで直接開くだけで動作します。ローカルサーバーを使う場合は例えば：

```bash
cd spi-quiz-app
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHubにアップロードする

1. GitHubで新しいリポジトリを作成する（例：`spi-quiz-app`）
2. このフォルダの中身（`index.html` / `style.css` / `script.js` / `README.md`）をリポジトリ直下に追加してコミット・プッシュする

```bash
git init
git add .
git commit -m "SPI判断推理・資料解釈トレーニングアプリ"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/spi-quiz-app.git
git push -u origin main
```

## GitHub Pagesで公開する

1. GitHub上でリポジトリの **Settings → Pages** を開く
2. 「Build and deployment」の **Source** で `Deploy from a branch` を選択
3. **Branch** を `main`（フォルダは `/root`）に設定して **Save**
4. 数十秒〜数分後、`https://<あなたのユーザー名>.github.io/spi-quiz-app/` で公開されます

以降はリポジトリにプッシュするだけで自動的にサイトが更新されます。

## 分野ごとの公開／非公開を切り替える

精査中でまだ生徒に見せたくない分野がある場合は、`script.js`冒頭の`CATEGORIES`配列で該当する分野の`enabled`を`false`に書き換えてください。

```js
{ id: 'flow', label: '物の流れと比率', desc: '...', group: 'judgment', enabled: false },
```

`enabled: false`にした分野は、設定画面の出題範囲一覧から完全に非表示になります（生徒側からは存在自体が見えません）。GitHub上でscript.jsを編集してコミットすれば、数十秒〜数分でサイトに反映されます。

設定画面の出題範囲は「判断推理」「数的推理」「資料解釈」の3グループに分けて表示され、各グループの見出し横にある「全て解除／全て選択」ボタンでグループ単位のオン・オフも可能です。

## カスタマイズのヒント

- `script.js` 冒頭の `TIME_BASE`（制限時間）や `ELEMENT_COUNTS`（分野ごとの人数・チーム数のレンジ）を変更すると、難易度の感覚を調整できます。
- `CATEGORIES` 配列にラベルや説明文があるので、出題範囲のUI表示文言はここを編集してください。
- 対応推理のテーマ（果物・部署・色）や資料解釈の店舗名などは `script.js` 内のプールを編集すれば増やせます。
- 物の流れと比率のノードラベルや比率の候補は `FLOW_LABELS` / `FLOW_PERCENT_RATIOS` / `FLOW_FRACTIONS` で調整できます。
